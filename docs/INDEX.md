## Documentation Rules

- Current facts belong in the relevant core document.
- Dated decisions and verification evidence belong in the audit archive.
- Agent activity belongs in the appropriate worklog.
- Do not claim Quest validation without physical-device evidence.
- When documents disagree, resolve the conflict in an appended audit entry and
  update the authoritative current document.
